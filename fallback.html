Interface Introuvable

L'agent ChronoMAD n'a pas pu charger l'interface utilisateur.

Si vous êtes en développement, assurez-vous que le serveur de développement frontend est lancé ou que le build frontend a été généré.

Si vous êtes en production, l'installation est peut-être corrompue.

Le processus d'arrière-plan (tracking) continue de fonctionner si une session était active.
